# 超越大陆美术资产规范

本目录用于承接游戏界面优化所需的美术规范、生成提示词、资产清单和接入约定。

## 目标

参考经典玄幻页游的信息密度和游戏感，但不复刻任何参考截图。项目最终视觉应保留自己的识别度：

- 玄幻大陆、魂师修炼、魂环魂骨、宗门与地图探索。
- 深色界面、金属边框、玉绿/魂蓝高光、品质色清晰。
- 地图和战斗应像真实游戏场景，不再像前端演示棋盘。
- 图标必须统一风格，可在 32px、48px、64px 下辨认。

## 资产目录

- `src/assets/backgrounds/`：主城、野外、战斗背景。
- `src/assets/maps/`：世界地图、大陆点位图、区域地图。
- `src/assets/ui/`：面板底图、装饰、按钮、HUD 组件。
- `src/assets/icons/spirit/`：武魂图标。
- `src/assets/icons/skill/`：魂技图标。
- `src/assets/icons/bone/`：魂骨图标。
- `src/assets/icons/item/`：物品、材料、药品、卷轴等图标。
- `src/assets/icons/system/`：角色、背包、地图、商店、任务等系统入口图标。
- `src/assets/icons/frames/`：品质边框、锁定、选中、冷却等通用叠层。

## 命名规则

所有文件使用小写 snake_case：

- 武魂：`spirit_<id>.png`
- 魂技：`skill_<id>.png`
- 魂骨：`bone_<id>.png`
- 物品：`item_<id>.png`
- 系统：`ui_<id>.png`
- 品质边框：`frame_quality_<quality>.png`

## 图标规格

- 源文件建议 512x512，接入时用 CSS 缩放。
- 主体居中，占画面 70%-82%。
- 背景为深色圆形/菱形能量底，不要纯透明空底。
- 不放文字，不放水印，不放 UI 说明。
- 需要边缘高光，方便在深色面板中识别。

## 品质色

- white: `#d8d8d8`
- green: `#43d97a`
- blue: `#3aa7ff`
- purple: `#b45cff`
- orange: `#ff9f2e`
- red: `#ff4242`

## 系别色

- strength: 赤金、暗红、铜黑，表现力量、武器、兽魂、破坏力。
- agility: 青蓝、紫影、银白，表现速度、羽翼、利爪、残影。
- intelligence: 翠绿、魂蓝、紫金，表现法阵、植物、宝石、控制、治疗。

## 面板风格

- 深色半透明主面：墨黑、深青、暗蓝。
- 外框：暗金金属线，局部磨损和内发光。
- 高亮：选中态用青蓝或魂绿光，不用大片纯亮色。
- 内容区可高密度，但留出清晰分隔线。

## 地图风格

- 主城：俯视/斜俯视的玄幻城市场景，建筑入口明确。
- 世界地图：大陆地形大图，区域点位、等级段、阵营可叠加。
- 野外战斗：真实背景场景，UI 贴边，不遮挡角色和怪物。
